Git Learning Guide

What is Git?

Git is a distributed version control system that helps developers track changes in their code and collaborate with others.

Initialize a Repository

Create a new Git repository in your project folder:

git init

Check Repository Status

See which files are tracked, modified, or staged:

git status

Stage Changes

Add files to the staging area:

git add .

Commit Changes

Save a snapshot of your project:

git commit -m "Initial commit"

View Commit History

Show all commits:

git log --oneline

Connect to GitHub

Add a remote repository:

git remote add origin https://github.com/username/repository.git

Push Code to GitHub

git push -u origin main
